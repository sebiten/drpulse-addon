# Drpulse 2.0.0-beta.7

October 16, 2026

## Settings redesign

- New sidebar navigation with descriptions for General, Appearance, Detection, Tools and Guide.
- Clearer section headings, more space between controls and fewer decorative boxes.
- Compact On/Off controls with visible state indicators.
- Donation link remains visible in a fixed footer while browsing settings.
- Settings window scales down to fit smaller screens.

Existing options and tracking behavior are unchanged. Open the redesigned panel with `/drpulse`.
