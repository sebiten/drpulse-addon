# Drpulse 2.0.0-beta.6

October 16, 2026

## Added

- **Icon font selector:** Choose Game default, Friz Quadrata, Arial Narrow, Morpheus or Skurri for timers and stack text on the target and enemy nameplates.
- **Flexible nameplate positioning:** Adjust horizontal and vertical icon offsets from -300 to 300 pixels, in addition to the existing above/below placement and separation.

## Improved

- Settings previews reflect font and positioning changes immediately and scale to fit larger offsets.
- Reset appearance restores the new font and positioning settings to their defaults.
- Existing saved settings retain their current appearance. Unavailable fonts fall back to the game's default font.

Find the new options under `/drpulse` → **Appearance**.
